# 🐄 쇼핑 흑우(Black Cow) 감별사 — SRS

## 1. 문서 개요
### 1.1 목적
본 문서는 “쇼핑 흑우 감별사” 프로젝트의 소프트웨어 요구사항을 정의한다.

### 1.2 범위
온라인 쇼핑몰 상품 정보를 수집·분석하여 짝퉁 및 사기 가능성을 판정하고 설명 가능한 근거를 제공한다.

## 2. 전반적 설명
- 사용자 입력: 상품 링크 또는 제품명
- 출력: 위험도 점수 및 상세 분석 결과
- 대상: 일반 소비자

## 3. 기능 요구사항
| ID | 기능 | 설명 | 우선순위 |
|----|------|------|----------|
| F-01 | 가격 이상치 탐지 | Median + MAD 기반 | 상 |
| F-02 | 판매자 신뢰도 분석 | 계정 연령, 정책 등 | 상 |
| F-03 | 콘텐츠 분석 | 이미지/OCR | 중 |
| F-04 | 리뷰 패턴 분석 | 리뷰 조작 탐지 | 중 |
| F-05 | 위험도 점수화 | BRS 산출 | 상 |
| F-06 | 시각화 | Reason Code 제공 | 상 |

## 4. 비기능 요구사항
| 항목 | 내용 |
|------|-------|
| 성능 | 평균 응답 5초 이내 |
| 확장성 | 사이트 추가 용이 |
| 보안 | HTTPS, API Key 보호 |
| 접근성 | 모바일/PC 지원 |

## 5. 데이터 요구사항
| 데이터 | 출처 | 사용 목적 |
|--------|------|-----------|
| 가격 | 쿠팡, 네이버 | 이상치 탐지 |
| 판매자 | 판매자 페이지 | 신뢰도 분석 |
| 리뷰 | 상품 리뷰 | 조작 탐지 |
| 이미지 | 썸네일/공식 | 짝퉁 판별 |
| 브랜드 DB | 공식몰 | 정품 인증 |

## 6. 시스템 아키텍처
```
[Front-End] React/Vue
    ↓ REST API
[Spring Boot Backend]
 ├─ Crawler Service
 ├─ Price Service
 ├─ Seller Service
 ├─ Content Veracity Service
 ├─ Review Service
 ├─ Risk Engine (BRS)
 └─ Recommendation Service
    ↓
[MySQL] [Redis] [S3]
[GPT API + Rekognition + OCR]
```

## 7. 인터페이스 요구사항
- POST /analyze
- Request: { "url": "..." }
- Response: BRS 점수, Reason Code, 분석 결과
