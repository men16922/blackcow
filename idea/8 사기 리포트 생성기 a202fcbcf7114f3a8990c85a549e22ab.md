# 사기 리포트 생성기

## 개념 요약

AI 분석 결과를 자동으로 PDF 형태의 리포트로 만들어주는 기능.

결과를 저장하거나 공유할 수 있도록 지원한다.

## 기능 흐름

1. 분석 완료 후 “리포트 다운로드” 버튼 클릭.
2. 서버에서 ReportLab 또는 jsPDF로 PDF 생성.
3. 결과 요약, 점수 그래프, 대안 상품 포함.

## 구현 전략

- Python ReportLab 또는 jsPDF 사용.
- 로고, BRS 차트, 날짜 삽입.
- 서버에 임시 저장 후 다운로드 링크 제공.

## 기술 포인트

- PDF 헤더/푸터 일관성 유지.
- 폰트 임베딩 (한글 대응).
- 파일명: `fraud_report_{timestamp}.pdf`

## 사용자 가치

- 분석 결과를 외부에 쉽게 공유 가능.
- 기업 제휴/포트폴리오 확장성 높음.
- “출력물로 남는 서비스”로 신뢰도 상승.
