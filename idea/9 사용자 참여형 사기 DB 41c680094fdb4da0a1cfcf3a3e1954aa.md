# 사용자 참여형 사기 DB

## 개념 요약

사용자가 사기 의심 상품을 신고하고, 다른 사용자가 투표로 신뢰도를
평가하는 기능.

커뮤니티 기반 데이터 축적 구조.

## 기능 흐름

1. 분석 결과 페이지에 “신고하기” 버튼 추가.
2. 신고 시 URL, 사유, 사용자ID 저장.
3. 다른 사용자는 Good/Bed 투표 가능. (혹은 단순 up/down 도 가능)

## 구현 전략

- MongoDB `fraud_reports` 컬렉션 생성.
- 필드: { url, reason, votes, createdAt }.
- 간단한 사용자 인증 (익명 가능).

⇒ Example 

## 기술 포인트

- 신고 수 기준 자동 경고 표시.
- AI 학습 데이터로 활용 가능.
- 투표 결과에 따라 신고 신뢰도 조정.

## 사용자 가치

- 커뮤니티 데이터 기반으로 AI 개선 가능.
- 사용자 참여 유도 → 플랫폼 신뢰도 상승.
- “집단지성형 사기 감별 시스템”으로 확장 가능.
