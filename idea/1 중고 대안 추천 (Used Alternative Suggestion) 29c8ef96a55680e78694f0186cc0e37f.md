# 1. 중고 대안 추천 (Used Alternative Suggestion)

**이 기능 자체는 상품명 정규화가 어려워 구현이 힘들 수 있음**

### 개념 요약

> “새 상품이 위험하거나 비싸면, 중고로 안전하고 싼 선택지를 보여준다.”
> 
- 현재 BRS(흑우 위험도)가 일정 수준 이상이거나
- 새 상품 평균가보다 비쌀 경우
- 자동으로 중고 거래 플랫폼(예: 번개장터, 당근, 중고나라, 네이버 중고나라 등)에서
    
    동일 상품 검색 후 “중고 대안 카드”를 함께 출력한다.
    

```jsx
흑우 위험도: 78% (높음)
새 상품 평균가: 149,000원

추천 대안:
1. 쿠팡 로켓배송 - 98,000원 (공식)
2. 네이버 공식스토어 - 99,500원
3. 중고나라 - 82,000원 (서울 직거래, 상태 ‘상’) ⭐

AI 한마디:
“현재 새 제품보다 17% 저렴한 중고 대안이 있습니다.
판매자 평판이 양호하며, 실사진이 등록되어 있습니다.”

```

### 기능 흐름

```
[사용자 입력]
 → URL 분석 (상품명 추출)
   ↓
[상품명 기반 중고 검색 API 호출]
   ↓
[가격 / 지역 / 상태 / 판매자 신뢰도 필터링]
   ↓
[중고 대안 카드 생성]
```

### 구현 전략

```
구현 전략

상품명 정규화 (예: “아이폰 15 프로 256GB”)

번개장터 크롤링 → <title>, <price>, <location> 추출

최근 10개 결과에서 3개만 노출

가격이 새 제품 대비 15% 이상 저렴한 항목만 표시

결과는 “추천 대안” 섹션에 append
```
