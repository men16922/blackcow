# 판매자 평판 카드

**이 기능 자체는 여러 사이트의 판매자 프로파일링이 어렵기 때문에 구현이 힘들 것으로 예상** 

## 개념 요약

판매자별로 누적된 분석 결과를 요약하여 카드 형태로 표시하는 기능.

판매자 계정 신뢰도, 부정 리뷰 비율, 과거 탐지 이력 등을 포함한다.

## 기능 흐름

1. 분석 시 판매자명과 관련 데이터 저장.
2. 동일 판매자 재등장 시 이전 데이터 불러옴.
3. 판매자 프로필 카드에 최근 3회 결과 요약 표시.

## 구현 전략

- MongoDB에 `seller_profiles` 컬렉션 생성.
- 각 판매자 document에 누적 점수, 거래 횟수, 부정 비율 기록.
- Redis로 캐시 → 빠른 프로필 조회.
- 카드 UI: React + Tailwind 구성.

## 기술 포인트

- 신뢰 점수(SCS): 0~100점.
- 최근 부정 패턴 감지 시 경고 아이콘 표시.
- 판매자별 URL 링크 제공 (상품 목록 조회용).

## 사용자 가치

- 반복 판매자의 위험도 추적 가능.
- 신뢰도 카드로 사용자 결정 지원.
- 사기 판매자 DB 확장 기반 구축.
