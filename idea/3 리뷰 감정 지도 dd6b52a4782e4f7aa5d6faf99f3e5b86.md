# 리뷰 감정 지도

## 개념 요약

리뷰 데이터를 긍정, 중립, 부정으로 분류하고, 그 결과를 시각적으로
표현하여 제품의 신뢰도를 감정 분포 기반으로 보여준다.

## 기능 흐름

1. AI 기반 API 통해 리뷰 텍스트 감정 분류 수행.
2. 각 리뷰에 sentiment 태그 부여 (positive/neutral/negative).
3. Chart.js 기반 Pie Chart 또는 Word Cloud 생성.
4. 사용자는 긍정/부정 키워드 목록을 확인 가능.

## 구현 전략

- 리뷰 감정 데이터는 DB에 JSON 배열로 저장.
- “부정 키워드” 상위 5개를 워드 클라우드로 표시.
- 분석 결과를 매 요청 시 재활용할 수 있도록 캐싱.
- Ai 프롬프트 설계 예: “리뷰를 감정별로 분류하고 핵심 키워드를
요약하라.”

## 기술 포인트

- Claude Sonnet / GPT-4 API 등 AI 기반 API 사용, 감정 분석 후 구조화된 JSON 반환.
- Chart.js 혹은 다른 CHART 기반 JS 를 통해 원형 차트 구성. (혹은 Word Cloud)

—> Word Cloud 의 경우 워드 클라우드 생성 라이브러리(D3.js or react-wordcloud) 등 연동

## 사용자 가치

- 복잡한 리뷰를 감정 시각화로 단순화.
- “AI 분석 결과가 눈에 보인다”는 신뢰감 제공.
- 사용자 UX 향상 및 시연 효과 극대화.
