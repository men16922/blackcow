# AI 추천 코멘트

## 개념 요약

AI가 분석 결과를 요약하여 사용자에게 자연어로 조언을 제공하는 기능.

“이 상품은 최근 리뷰 폭증이 감지되었습니다. 주의가 필요합니다.” 같은
문장 생성.

## 기능 흐름

1. 분석 완료 후 결과(JSON)를 AI에 전달.
2. AI가 자연어 설명 요약을 생성.
3. UI 하단에 “AI 코멘트” 영역으로 표시.

## 구현 전략

- AI 프롬프트 설계: “다음 분석 결과를 한국어로 간결하게 설명하라.”
- 응답 JSON: `{ summary: "...", tone: "neutral"|"alert"|"safe" }`
- 톤에 따라 UI 색상 변경 (green/orange/red).

## 기술 포인트

- 텍스트 길이 제한 관리.
- 캐싱을 통해 중복 API 호출 방지.
- 에러 발생 시 fallback 문장 표시.

## 사용자 가치

- 단순 점수 이상의 ‘이해 가능한 설명’ 제공.
- AI의 개입을 체감하게 해줌.
- 시연 시 완성도 높고 인상 깊은 기능.
