# 상품 비교 카드

## 개념 요약

두 개의 상품 URL을 동시에 입력받아 가격, 리뷰, 리스크, 판매자 정보를
비교하는 기능.

## 기능 흐름

1. 사용자 입력에서 두 개의 URL 추출.
2. 각각의 상품 분석 결과를 병렬로 수행.
3. 항목별 차이를 비교표 형태로 시각화.
4. 최종 추천 상품을 표시.

## 구현 전략

- Express에서 Promise.all()로 병렬 API 호출.
- React UI에서 테이블 형태 비교 출력.

⇒ 위 사항은 예시 임 

- 차이가 큰 항목은 색상 강조.

## 기술 포인트

- BRS, 가격, 리뷰점수, 판매자 점수 비교.
- 동일한 스케일로 시각화 (Radar Chart 가능).
- 병렬 처리 성능 튜닝.

## 사용자 가치

- “이게 더 낫다”를 명확하게 시각화.
- 구매 결정 지원.
- 발표 시 시각적으로 강력한 데모 포인트.
