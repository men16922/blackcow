# 2. 리스크 타임라인 (Risk Timeline)

---

### 개념

상품을 여러 번 분석할 때 과거 분석 결과를 저장하여, 시간에 따라 흑우
위험도가 어떻게 변했는지를 시각화한다.

### 기능 흐름

1. 사용자가 동일 상품을 재분석할 때 결과를 DB에 저장
2. 상품명 기준으로 과거 BRS 히스토리 조회
3. Line Chart 형태로 시각화 (예: Chart.js)

### 기술 포인트

- MongoDB TTL을 30일 이상으로 확장
- BRS 점수, 가격 평균, 판매자 신뢰도 변화량 저장
- Chart.js로 React 내 그래프 출력

### 사용자 가치

- 위험도의 추세를 한눈에 확인 가능
- “사기 탐지 AI”로서의 신뢰도 상승
- 반복 사용 유도 (Retention 강화)
