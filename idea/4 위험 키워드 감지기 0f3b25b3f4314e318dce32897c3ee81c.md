# 위험 키워드 감지기

## 개념 요약

상품 설명, 제목, 리뷰 텍스트에서 사기성·마케팅성 단어를 자동 탐지하여
강조 표시하는 기능.

예: “정품 보장”, “공식몰”, “가성비 최고”, “원가 이하” 등.

## 기능 흐름

1. 상품 데이터 및 리뷰 텍스트 수집.
2. 사기 키워드 사전(JSON) 기반으로 탐지.
3. 일치 단어에 하이라이트 스타일 적용.
4. AI 를 사용해 마케팅성 단어를 자동 추출해 사전 업데이트.

## 구현 전략

- 서버 측에서 정규식 기반 탐지.
- 클라이언트 측에서 하이라이팅 렌더링
- 주기적으로 AI 에게 “새로운 키워드 후보” 요청 → 사전 확장.

## 기술 포인트

- 키워드 가중치 기반 위험도 표시 (예: “공식”=1점, “정품보장”=2점).
- Front-End Markdown 렌더링 시 highlight 적용.

## 사용자 가치

- 사기성 표현을 한눈에 식별 가능.
- AI의 ’설명력’을 시각적으로 강화.
- 구현이 단순하면서 UX 임팩트 큼.
